# RUBSARB WHATEVER - intro

Chrome Extension เล่นอินโทร WHATEVER 20 วินาทีก่อนคลิปช่อง RUBSARB เฉพาะเมื่อเริ่มคลิปที่ 00:00 พร้อมปุ่มข้ามอินโทร

[ดาวน์โหลด ZIP เวอร์ชัน 1.0.3](./rubsarb-whatever-intro-v1.0.3.zip)

## ติดตั้งจาก ZIP

1. ดาวน์โหลดและแตก ZIP
2. เปิด `chrome://extensions` และเปิด Developer mode
3. กด Load unpacked แล้วเลือกโฟลเดอร์ `rubsarb-intro` ที่มี `manifest.json`
4. รีเฟรช YouTube

รองรับหน้าคลิปปกติ `/watch` ยังไม่รองรับ Shorts หรือวิดีโอฝังในเว็บไซต์อื่น
ลิงก์ที่ระบุเวลาเริ่มมากกว่า 0 และการเล่นต่อจากกลางคลิปจะข้ามอินโทร
