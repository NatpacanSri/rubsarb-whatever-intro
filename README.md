# RUBSARB WHATEVER - intro

Chrome Extension เล่นอินโทร WHATEVER 20 วินาทีก่อนคลิปช่อง RUBSARB เฉพาะเมื่อเริ่มคลิปที่ 00:00 พร้อมปุ่มข้ามอินโทร

[ดาวน์โหลด ZIP เวอร์ชัน 1.1.0](./rubsarb-whatever-intro-v1.1.0.zip)

## ติดตั้งจาก ZIP

1. ดาวน์โหลดและแตก ZIP
2. เปิด `chrome://extensions` และเปิด Developer mode
3. กด Load unpacked แล้วเลือกโฟลเดอร์ `rubsarb-intro` ที่มี `manifest.json`
4. รีเฟรช YouTube

รองรับหน้าคลิปปกติ `/watch` ยังไม่รองรับ Shorts หรือวิดีโอฝังในเว็บไซต์อื่น
ลิงก์ที่ระบุเวลาเริ่มมากกว่า 0 และการเล่นต่อจากกลางคลิปจะข้ามอินโทร

[นโยบายความเป็นส่วนตัว](https://natpacansri.github.io/rubsarb-whatever-intro-privacy/)

## ตัวกรองในรุ่น 1.1.0

กดไอคอนส่วนขยายข้างช่องที่อยู่เพื่อเปิดหน้าตั้งค่า

- เปิด/ปิดอินโทรเฉพาะคลิปได้ และล้างเพื่อกลับไปใช้ตัวกรองอัตโนมัติได้
- ค่าเฉพาะคลิปมีลำดับสูงกว่าตัวกรองคำ
- เปิด/ปิดตัวกรองทั้งหมด หรือเปิด/ปิดแต่ละคำ เพิ่มคำและลบคำได้
- ค่าเริ่มต้นข้าม WHATEVER, GGCooking, Gameboys, ศิลปะล่ะ, รับบิน, 8ท, ทททททททท, ล้านก้าว, กินจิต กินใจ
- จับคำในชื่อคลิปโดยไม่สนตัวพิมพ์ใหญ่–เล็ก ช่องว่าง และเครื่องหมาย
- บันทึกเฉพาะค่าตั้งและคลิปที่เลือกตั้งค่าเองไว้ในเครื่อง ไม่ซิงก์และไม่ส่งข้อมูลออก

อัปเดตจากรุ่นเดิมโดยแตก ZIP แทนไฟล์ในโฟลเดอร์เดิม กด Reload ใน chrome://extensions แล้วรีเฟรชแท็บ YouTube
อินโทรยังเล่นเฉพาะตอนเริ่มที่ 00:00 การเปิดระหว่างดูจะไม่แทรกอินโทรกลางคลิป

### การตรวจรุ่นนี้

ทดสอบตรรกะและหน้าตั้งค่าด้วย Chrome API จำลองแล้ว ยังไม่ได้ติดตั้งแพ็กเกจ 1.1.0 เพื่อทดสอบกับ YouTube จริง
